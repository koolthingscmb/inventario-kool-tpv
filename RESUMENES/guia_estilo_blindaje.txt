PROMPT DE BLINDAJE ARQUITECTÓNICO Y UI (ESTÁNDAR KOOL_V2)
══════════════════════════════════════════════════════════

OBJETIVO:
Consolidar la identidad visual Matrix y blindar la lógica de validación de datos. A partir de ahora, todo el sistema debe regirse por estos estándares inamovibles.
🎨 1. BLINDAJE ESTÉTICO (SISTEMA DE DISEÑO)

Para asegurar que todos los módulos (Almacén, Clientes, Shopify, etc.) sean idénticos, debes aplicar estos valores fijos en utils/templates/base_module_view.py:

    Sidebar (Inamovible): Ancho fijo de 220px. Fondo #393E46.

    Zona Central (Fondo): Siempre #1a1a1a (Negro profundo).

    Sistema de Ruta (Breadcrumbs): Implementar en la parte superior de la zona central un CTkLabel persistente que muestre la ruta: SISTEMA_KOOL_TPV: / [MODULO] / [SUB_SECCION].

        Fuente: Courier New, 12px, negrita. Color: #00FF00.

    Cero Flicker: Todas las pestañas (Tabs) y frames de contenido deben tener fg_color="#1a1a1a" para garantizar transiciones totalmente negras.

⌨️ 2. BLINDAJE DE BUSCADORES (SearchableCombo PRO)

Debes refactorizar el componente SearchableCombo para que sea una herramienta de alta productividad:

    Navegación Remota (Sin pérdida de foco):

        Las flechas Arriba/Abajo y la tecla Enter deben controlar la lista de sugerencias sin que el cursor abandone el Entry.

        El evento KeyRelease debe ignorar estas teclas de navegación para no regenerar la lista mientras se navega.

    Validación Estricta (Strict Mode):

        Al dispararse el evento FocusOut (salir del campo), el componente debe verificar si el texto existe en la base de datos.

        Si es inválido: Cambiar el border_color a Rojo (#FF0000) inmediatamente.

        Si es válido: Mantener el border_color en Verde (#00FF00).

📊 3. ESTÁNDAR DE FORMULARIOS (GRID 8 COLUMNAS)

Todos los formularios complejos (como Crear Producto) deben usar un Grid de 8 columnas para una alineación perfecta.

    Usar columnspan para equilibrar filas (ej. ID: 2 col, Nombre: 6 col).

    Las etiquetas (Labels) deben usar siempre la fuente Courier New en verde.

    Los cuadros de texto largos (SEO Description, Descripción Web) deben ser CTkTextbox.

💾 4. BLINDAJE DE DATOS (TRANSACCIONES SQL)

El botón de Guardado debe ser atómico. No se permite guardar un producto si su precio falla.

    Validación Previa: Si algún SearchableCombo tiene el borde en Rojo (inválido) o get_id() es None, el guardado se aborta con un show_error.

    Atomicidad: Usar BEGIN TRANSACTION y COMMIT para asegurar que las tablas productos y precios se actualicen simultáneamente.

✅ CRITERIO DE ACEPTACIÓN FINAL:

    La navegación por el almacén es fluida y muestra la ruta arriba: ALMACEN / CREAR.

    No es posible guardar una categoría inexistente (como "Libretilla").

    El usuario puede rellenar todo el formulario usando solo el teclado (Tab, flechas y Enter).

    Visualmente, la app es consistente: 220px de sidebar y estética Matrix impecable.
